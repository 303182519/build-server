4. 配置说明

BULL_BOARD_ENABLED是否启用面板（默认 true）
BULL_BOARD_PATH面板挂载路径（默认 /admin/queues）
BULL_BOARD_AUTH_TYPE认证类型：jwt（校验 JWT + 特殊角色）/ none（无认证）
BULL_BOARD_READ_ONLY只读模式：true = 仅查看，禁止操作（默认 false）
注意：JWT 认证模式要求 JWT payload 中包含 specialRoles 字段， 且值为 super_admin 或 developer。 如果签发 token 时未写入该字段，所有用户都会被面板拒绝（403）。

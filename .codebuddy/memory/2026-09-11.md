# 2026-09-11

## 修复 logger.module.ts 类型编译错误（TS2339）

- 现象：`src/shared/logger/logger.module.ts` 中 `targets.push(...)` 报 TS2339，`targets` 被推断为 `readonly (... )[]`。
- 根因：pino/nestjs-pino 中 `transport.targets` 类型声明为 readonly 数组，`PinoTransportTargets = Extract<...>['targets']` 继承了 readonly，无法调用 `push`。
- 修复：先取元素类型，再重声明为可变数组：
  - `type PinoTransportTarget = Extract<NonNullable<PinoHttpOptions['transport']>, { targets: unknown }>['targets'][number];`
  - `type PinoTransportTargets = PinoTransportTarget[];`
- 仅类型层改动，运行时行为不变（写入 `{ transporter: { targets } }` 不受影响）。

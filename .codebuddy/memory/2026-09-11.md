# 2026-09-11

## 修复 logger.module.ts 类型编译错误（TS2339）

- 现象：`src/shared/logger/logger.module.ts` 中 `targets.push(...)` 报 TS2339，`targets` 被推断为 `readonly (... )[]`。
- 根因：pino/nestjs-pino 中 `transport.targets` 类型声明为 readonly 数组，`PinoTransportTargets = Extract<...>['targets']` 继承了 readonly，无法调用 `push`。
- 修复：先取元素类型，再重声明为可变数组：
  - `type PinoTransportTarget = Extract<NonNullable<PinoHttpOptions['transport']>, { targets: unknown }>['targets'][number];`
  - `type PinoTransportTargets = PinoTransportTarget[];`
- 仅类型层改动，运行时行为不变（写入 `{ transporter: { targets } }` 不受影响）。

## LOG_OUTPUT 取值收敛为 console | file，默认 console

- 需求：去掉 `both`，默认值由 `both` 改为 `console`。
- 同步修改点（保持单一真相源一致）：
  - `.env`：注释与 `LOG_OUTPUT=console`
  - `src/config/env.validation.ts`：`Joi.string().valid('console', 'file').default('console')`
  - `src/config/config.default.ts`、`src/config/configuration.ts`：fallback `'both'` → `'console'`
  - `src/config/configuration.interface.ts`：`output?: 'console' | 'file'`
  - `src/shared/logger/logger.module.ts`：`wantConsole/wantFile` 去掉 both 分支
  - `src/shared/logger/README.md`：文档同步
- 风险：外部环境若仍配置 `LOG_OUTPUT=both`，Joi 校验会直接启动失败（预期破坏性变更），需同步其他环境配置文件。
- 未执行校验：本机 execute_command 环境异常（spawn bash ENOENT），tsc/lint 未能实际运行。

## pino-pretty 仅限 development 使用

- 需求：控制台美化输出（`pino-pretty`）只能在 development 生效。
- 改动：
  - `src/shared/logger/logger.module.ts`：判定条件由「`!jsonFormat`」改为「`IsDev && !jsonFormat`」（引入 `@/common/constants/environment` 的 `IsDev`），移除了本地 `isProduction` 变量；非开发环境统一 `pino/file` 输出 stdout JSON。
  - `package.json`：`pino-pretty` 由 `dependencies` 移到 `devDependencies`（生产镜像 `pnpm install --prod` 不再安装它）。
  - `pnpm-lock.yaml`：手动把 importers 中的 `pino-pretty` 从 dependencies 移到 devDependencies（`--frozen-lockfile` 要求 lockfile 与 package.json 一致）。
  - `src/shared/logger/README.md`：控制台格式表 + 故障排查段同步。
- 设计理由：不能按「非生产即美化」判定，否则 staging/test/未设 NODE_ENV 且用 --prod 安装时会因缺包导致 transport 初始化即崩。
- 已知遗留（非本次引入）：`pnpm-lock.yaml` 中缺失 `pino-roll`（package.json 已声明 `^4.0.0`），lockfile 与 package.json 本就不同步，`pnpm install --frozen-lockfile` 会失败，需重跑 `pnpm install` 重新生成。本机 shell 不可用（spawn bash ENOENT），未能运行 tsc/lint/build。
